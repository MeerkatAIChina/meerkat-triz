## Critical Blockers

### BLK-01: Notebook 05 Layer 1 comparison is broken

- **Flow:** Notebook 03 → `pipeline_state['baseline_results']` → Notebook 05 → `aggregate_results(..., before_results, after_results)`
- **Issue:** Notebook 03 registers `baseline_results` with Layer 1 scores stored on disk at `path`, but only metadata (`model_path`, `tasks`, `triz_summary`, `perf_throughput`) in the `metadata` field. Notebook 05 loads `general_results = baseline.get('metadata', {})`, so `aggregate_results()` receives metadata instead of actual Layer 1 benchmark scores.
- **Result:** The before/after Layer 1 delta table shows task names and paths, not MMLU-Pro/GPQA/HumanEval/MATH/BBH scores.
- **Affected requirements:** EVAL-01, EVAL-05, BENCH-05
- **Fix:** In Notebook 05, load the JSON file at `baseline['path']` and extract `layer1_general` scores before passing to `aggregate_results()`, or change Notebook 03 to embed Layer 1 scores directly in `metadata`.

## Integration Warnings

### WARN-01: `requirements.txt` dependency pinning regressed
- **Expected:** Pinned versions per Phase 01 (transformers==4.45.0, peft==0.12.0, bitsandbytes==0.43.3, etc.)
- **Actual:** Current `requirements.txt` uses `>=` ranges and targets Transformers v5 (`transformers>=5.2.0`, `peft>=0.18.0`, `trl>=1.0.0`, `accelerate>=1.0.0`)
- **Affected requirement:** INFRA-04

### WARN-02: Seed count mismatch
- **Expected:** 548 seed samples
- **Actual:** `sample_data.json` contains 385 samples after duplicate removal (commit `2f72fa6`)
- **Affected requirement:** DATA-01

### WARN-03: Phase 03 test files at wrong path
- **Expected:** `ref/mongoose_ai_dgx/tests/test_format_messages.py`, `test_metrics.py`, `test_report.py`
- **Actual:** Files are at repo root `tests/`, not under `ref/mongoose_ai_dgx/tests/`
- **Affected requirements:** EVAL-01–EVAL-05

### WARN-04: `format_messages()` not exported from `utils/__init__.py`
- `utils/__init__.py` does not import/export `format_messages`
- **Affected requirements:** DATA-05, EVAL-03

### WARN-05: Training code duplicates `format_messages()` logic
- `training_utils.create_trainer()` defines its own `formatting_func` instead of using `data_utils.format_messages()`
- **Affected requirement:** DATA-05

### WARN-06: Notebook 05 ignores `adapter_checkpoint` pipeline_state entry
- Notebook 04 registers `adapter_checkpoint`; Notebook 05 hardcodes `os.path.join(MODELS_DIR, 'meerkat_triz_adapter_v1')`
- **Affected requirements:** TRAIN-08, EVAL-01–EVAL-05

### WARN-07: Notebook 04 preflight does not use `PipelineState`
- Summary claims preflight verifies `baseline_results`/`processed_dataset` via pipeline_state, but cell 2 only checks filesystem paths
- **Affected requirements:** TRAIN-01, INFRA-06

### WARN-08: Notebook 04 ignores `synthetic_dataset` pipeline_state artifact
- Notebook 02b registers `synthetic_dataset`; Notebook 04 loads from `DATA_CONFIG['processed_data_dir']`
- **Affected requirements:** INFRA-06, DATA-04

### WARN-09: Notebooks 02c/02d not integrated and overwrite shared output
- `02c_build_corpus_from_raw.ipynb` and `02d_build_sft_dataset_from_corpus.ipynb` exist but are not in documented workflow; 02d writes to same `processed_data_dir` as 02b
- **Affected requirements:** DATA-01, DATA-04, DATA-05

### WARN-10: Notebook 01 package versions inconsistent with `requirements.txt`
- Notebook 01 installs Phase 01 pinned versions while `requirements.txt` targets v5
- **Affected requirements:** INFRA-04, INFRA-09

### WARN-11: Test path mismatches
- `test_corpus_builder.py` and `test_benchmark_utils.py` use relative paths that fail depending on pytest invocation directory
- **Affected requirements:** INFRA-06, EVAL-01–EVAL-05

### WARN-12: `baseline_results` metadata uses wrong case-quality key
- Stores `case_quality_bleu`; `run_triz_evaluation()` returns `case_quality` dict
- **Affected requirement:** BENCH-05
