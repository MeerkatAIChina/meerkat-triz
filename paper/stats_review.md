## 2. 重大测量学发现:v4 金标 eval 的 base 被 think 草稿污染 ⚠️

### 2.1 事实链(全部有文件证据)

1. **base 100/100 题响应以 `<think>` 开头;其中 91/100 题 think 块从未闭合**(无 `</think>`,即 1024 token 预算被英文思考草稿烧光、生成中途截断,**最终答案根本没产生**);仅 9/100 题有闭合 think + 正文。(`paper/data/eval_v4_base_gold_20260723_105438.json` records 逐题验证)
2. 生成侧:`eval_harness.py:94-99` 虽用 `enable_thinking=False` 渲染 prompt 并剥空 think 前缀,但 base 模型仍以普通文本自吐 `<think>`;v2/v4 响应 0/100 含 think;v3 为 100/100 空 think(`<think>\n\n</think>`,think_end=9)+ 正文(正文均长 326 字)——**v2/v3/v4 测量的是真实答案,只有 base 不是**。
3. 关键词轨:`keyword_score`(L174-180)在**原始响应**上做子串匹配 → base 的 0.3661 是在英文思考草稿里命中的。
4. judge 轨:`build_judge_user`(L249-259)取 `response[:1500]`、**无 think 剥离** → base 91 题的"AI 回答"是 1500 字符的英文推理草稿,judge 从未看到中文正式答案。base 响应均长 3671 字符,judge 可见比例均值仅 43%(v2/v4 为 100%)。

## 7. 新分析⑤:judge 同源风险量化线索

- 若"同源偏袒"(judge 偏爱自家风格的回答)是主导因素,溢价应随训练数据 Moonshot 含量单调上升;**实测 v3(=v2 + 674 条 Moonshot ARIZ 补数据,Moonshot 含量最高)溢价全面回落,contradiction 轨 judge 分 0.100 为四方最低**——与同源偏袒假说方向相反。
- 备选解释:v3 的 ARIZ boost 数据本身质量差,judge(语义轨)识别出内容缺陷而关键词轨只看词汇命中。两假说均需异源 judge 裁决。
- **长度偏袒已排除**:gold 中 judge 分与响应长度 Spearman r=0.035~0.118,p>0.23(全部版本)。

### 7.3 结论与建议

同源风险**结构上存在、内部数据无法排除**,但现有溢价模式不支持"同源偏袒主导";真正受威胁的结论恰恰反向——eval2 中 v3 的 judge 低分若是"非偏袒证据",则 judge 轨整体可信度反而上升。**建议:用 ≥1 个异源 judge(GPT-4o / DeepSeek / Claude)重评 gold 100 题 × 4 版本(约 400 条 × 2k token,API 成本极低),若 v4≈v2 > base 的排序与量级保持,则全部主要结论对 judge 选择稳健;若 v4−base 差值缩水 >50%,则 judge 轨结论需整体重述。**
