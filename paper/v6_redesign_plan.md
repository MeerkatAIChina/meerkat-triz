# Meerkat-TRIZ 重设计方案（基于论文全部实测教训）
## v3 收敛版 · 2026-07-31 · 经三轮红队审计

---

## 0. 出发点：论文教会我们的七件事

| # | 教训 | 出处 | 对重设计的硬约束 |
|---|---|---|---|
| 1 | judge 轨增益基本全是长度伪影 | §5.3 等长对照 | 目标函数**不能再是"judge 分更高"** |
| 2 | 真实价值 = 等质 0.4× 篇幅 + 关键词韧性 | §5.3 | 把"信息密度"从意外副产物变成主目标 |
| 3 | 数据与质量门是唯一被验证的杠杆，超参贡献为零 | 五代谱系 | 预算 80% 给数据；超参冻结纪律延续 |
| 4 | keyword 逐词命中对 PR 子集部分失效 | D4 / 归因报告 | 度量先行：原理集合 F1 进 benchmark v2 |
| 5 | commit 式注入会丢框架词（v5b 双轨反向） | v5b 归因 | 数据契约扩展：原理覆盖 + 框架词双查 |
| 6 | 家族偏置沿**数据链**传播，不止生成链 | §6.3(iv) | 数据生成器必须跨家族 |
| 7 | 教材派生语料不可发布 | Limitation (iv) | 新语料必须可发布 → 专利路线 |

**一句话：v5a 意外发现了自己的价值主张（等质 0.4× + 关键词韧性），重设计让它从第一天起就是刻意目标。**

## 1. 目标定义（全部可机检，附验收线）

| 目标 | 定义 | 验收线 | 现状（v5a） |
|---|---|---|---|
| O1 信息密度 | 关键词命中 ≥ base 无约束水平，且长度 ≤ 0.5× base | 双条件同时满足 | 已达成（持平 + 0.41×）——**要保持并扩大** |
| O2 等质 | 等长对照下 judge n.s. | 同族 + ≥2 外部评委同时 n.s. 或显著为正 | 仅同族验证过；**外部等长臂未跑** |
| O3 PR 修复 | 原理集合 F1 显著 > base | benchmark v2 度量下 CI 下界 > 0 | base 0.254 / v5a 0.245 n.s.——未修复 |
| O4 通用能力 | 120 题 probe | ≥ −5pp（G6 现行标准） | −1.25pp，达标 |
| O5 长度可控（可选） | 指定长度带 ±10% 命中 | ≥ 80% | base 仅 6.7%（20/300）——若达成即是新卖点 |
| O6 可发布性 | 训练语料专利派生占比 | ≥ 70% → 数据集可公开 | 0%（教材派生，不可公开） |

## 2. 迭代过程（方案 → 审计 → 修正）

### 方案 v1（直觉版）

1. 专利语料整体替换教材语料
2. 长度条件化训练（prompt 内嵌长度 token）
3. PR 定向注入 v2（commit 风格但保留框架词）
4. 路由专家 LoRA（E5）+ rank 扫描并行
5. judge 分构造偏好对做 DPO
6. benchmark v2（原理 F1 + 英文子集）

### 审计 R1（红队）——四处开火

| # | 攻击点 | 依据 |
|---|---|---|
| A1 | **DPO 违反自家纪律**：论文 Limitation 明写"judge 未经人类验证前不做偏好优化，否则是蒸馏评委癖好进权重" | Limitation (vii) |
| A2 | **专利 ≠ TRIZ 教学文本**：从专利抽矛盾描述本身是未解决的 NLP 问题，直接全量替换 = 垃圾进垃圾出风险 | Altshuller 是人工读的专利 |
| A3 | **长度条件化可能教会"截断"而非"压缩"**：v5b 已演示过格式突变丢关键词表面 | v5b 归因 |
| A4 | **四变量并行打破单变量纪律**：出了问题无法归因，五代谱系的可解释性全部报废 | §6.2 |

### 方案 v2（修正）

- DPO 移到人类校准完成之后（依赖 AB 亲评 + 30 题人类研究）
- 专利语料先 200 条 pilot + 人工抽检 ≥90% 可用才扩产
- 放弃长度条件化新机制——训练数据本就有同题双风格配对，密度是数据属性不是架构属性
- 全部串行化：每代一个变量，每个变量独立过门

### 审计 R2——再中四枪

| # | 攻击点 | 依据 |
|---|---|---|
| B1 | **"信息密度"作主目标会重新激励堆关键词**——v3 就是这么死的 | §4.3 双轨分歧 |
| B2 | **原理 F1 的参考原理集仍派生自教材答案**——循环论证，度量自己需要锚定 | D4 报告 |
| B3 | **O2 无法验收**：外部评委从未在等长臂上跑过，测量短板不补，Phase 后面全是空中楼阁 | §5.3 未来工作 |
| B4 | **benchmark v2 与 v1 不可比**：换代即断代，谱系可比性报废 | 谱系纪律 |

### 方案 v3（收敛版）——四阶段串行，每阶段有过门/熔断

```
Phase 0  测量先行（2–3 周，纯 API，不动模型）
  ├─ 外部评委等长臂评审（3 评委 × 300 题）→ 补齐 O2 验收能力
  ├─ AB 亲评回收 + 30 题人类盲评 → judge-人类一致性量化
  └─ benchmark v2 alpha：PR 换原理 F1；60 题人工锚定子集；与 v1 桥接双口径
  熔断：judge-人类一致性 < 外部评委间一致性（ρ 0.63–0.75）→ Phase 3 永久冻结

Phase 1  数据（4–6 周，每变量一代）
  ├─ v6a = PR 修复 v2（commit 风格 + 框架词保留，数据契约双查）
  │   D1 契约 → D2 smoke40 → 全量 → 全决策门 + D5 等长伴随
  ├─ 专利 pilot 200 条（CN 专利矛盾描述抽取）→ 人工抽检 ≥90% 才扩产 2–3k
  └─ v6b = +专利语料（跨家族生成器 ≥2 个外部家族参与生成/校验）
  熔断：pilot 抽检 <90% → 专利路线降级为"教材清洗+改写"备用方案

Phase 2  训练消融（2 周，与 Phase 1 后期并行）
  ├─ E5：路由专家 LoRA vs 现行 12 共享投影（r=64 冻结）
  └─ rank 32/128 扫描（在胜出的覆盖方案上）
  熔断：任一代 G7/G8 不过 → 回退，归因报告强制

Phase 3  偏好优化（仅在 Phase 0 的 judge 人类校准通过后启动）
  ├─ 偏好对来源：等长对照下人类与外部评委一致胜出的配对（不是 judge 单方）
  └─ 小步 DPO + 全门验收
```

### 审计 R3（收敛检查）

- ✅ 每个目标可机检、每条线有熔断
- ✅ 单变量纪律恢复（v6a/v6b 分两代）
- ✅ 测量短板在动模型之前补齐（B3 解决）
- ✅ B1 解决：密度目标以"命中 ≥ base"约束表达（不许超量堆词），judge 地板 + 双轨门仍在
- ✅ B2 解决：60 题人工锚定子集为 F1 度量接地
- ✅ B4 解决：benchmark v2 alpha 与 v1 双口径桥接一代
- ⚠️ 残余风险（如实保留）：专利语料分布偏移（pilot 门控兜底）；人工标注进度依赖owner时间；总周期 8–11 周

## 2b. 评委仪器迁移协议（k3 / tensoris 升级触发的方案补丁，2026-07-31）

**触发条件**：moonshot API 升级 k3 长文本模型，或 tensoris 面板模型升级。
**核心判断**：judge 是测量仪器，不是工具——换 judge = 换仪器 =
五代谱系全部历史数字失去直接可比性。因此**桥接，不切换**，按一次
"测量代"（类比 v5 harness E0 修复）走完整流程。

### 风险登记

| 风险 | 后果 | 对策 |
|---|---|---|
| 缓存谱系断代 | 全部历史分数（3.030/3.423/+0.393…）是 v1-32k 读数，新旧不可直接比 | 桥接重评分（步骤 3） |
| T=0 确定性未验 | 翻转率 0.000 是钉版协议基石，k3 未知 | 步骤 2 重测 |
| rubric 行为漂移 | +0.463 压长响应、等长结论是特定评委行为 | 步骤 5 复跑 |
| 外部一致性基线失效 | G8 校准依据（ρ 0.63–0.75 / 0.27–0.31）作废 | 步骤 4 重算 |
| 浮动别名静默漂移 | "k3"/"latest" 中途换模型 | **D6 门规**：钉快照版本号，禁浮动别名 |
| 同族定义误解 | k3 仍是 Moonshot 家族 | 回避制/G8/"同族不可外推"照旧 |

### 七步迁移流程（Phase 0 前置，纯 API，不动模型）

1. **钉快照**：k3 与 tensoris 侧全部评委以具体版本号写入 harness 配置（D6）
2. **T=0 翻转率**：每新评委 50 题 × 3 次重复，翻转率须 ≤0.02 才可钉版
3. **桥接重评分**：base / v5a / base-等长 三个现有生成臂 × 新旧评委平行打分
   （生成文件全部在库，零生成成本）
4. **一致性报告**：新旧评委逐题 Spearman + 均值偏移；外部面板内部一致性
   重算为新的 G8 校准基线
5. **等长对照复跑**：新评委下 v5a−base(等长) 应仍为 n.s.——这是对论文
   §5.3 核心结论的跨仪器稳健性检验（审稿人必问，先发制人）
6. **双评委并行一代**：v6a 评测同时报新旧同族评委读数，之后旧版归档
7. **历史归档**：v1-32k 全部数字永久标注 judge 版本保留，新表带新评委标注

### 长文本升级的真实收益（不夸大）

- **Phase 1 专利路线是最大受益者**：专利全文上万字，k3 长上下文使
  "全文 → 矛盾描述抽取"单次完成，pilot 质量上限提高
- ARIZ 长报告评测、带 few-shot 范例的 judge prompt 成为可能
- tensoris 面板新鲜度对 arXiv 审稿是加分项
- **但**：新评委不等于更客观的评委；一切行为假设必须经步骤 2/5 重测

## 3. 与最佳实践的对齐声明

| 最佳实践 | 本方案落点 |
|---|---|
| 测量先于模型（eval-driven development） | Phase 0 整体 |
| 单变量实验 + 决策门 | 每代一变量 + G0–G8 + D1–D5 |
| 跨家族评委 + 回避制 | G8 + 数据生成器跨家族（新增） |
| 长度混淆控制 | D5 内建于每代评测，不再是事后补救 |
| 人类校准先于偏好优化 | Phase 0 熔断 → Phase 3 门锁 |
| 可发布性（数据集开放） | O6 专利路线 |
| 失败谱系公开 | 延续 v3/v4/v5b 惯例，每代归因报告入库 |
| 测量仪器版本钉死与迁移桥接 | D6（§2b）：钉快照、禁浮动别名、换评委必桥接 |

## 4. 预期效果（对 owner 的承诺线）

达成全线后，Meerkat-TRIZ v2 的对外口径将从 v1 的
"等质 0.4× + 关键词韧性（意外发现）"升级为：
**"等质 ≤0.5× + 关键词韧性 + PR 原理选择显著更强 + 三评委等长验证 +
人类校准过的 judge + 可公开数据集"**——且每一个字都有门检记录。
