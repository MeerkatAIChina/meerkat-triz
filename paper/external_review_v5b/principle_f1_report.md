# PR 原理集合 F1 报告（benchmark v2 候选度量，2026-07-31）

度量动机：keyword 逐词命中把 PR 的"选对原理"误测为"复现参考答案措辞"。
本度量从回答抽取 40 发明原理集合，与参考答案原理集合算 set F1。

| arm | mean F1 | mean |pred| | mean |ref| |
|---|---|---|---|
| base | 0.254 | 9.9 | 3.9 |
| v5a | 0.245 | 9.6 | 3.9 |
| v5b | 0.205 | 8.7 | 3.9 |

配对差值（paired bootstrap n=10000 seed=42）：
- v5a−base: −0.009 [−0.066, +0.049] n.s.
- v5b−base: −0.049 [−0.105, +0.007] n.s.
- v5b−v5a: −0.040 [−0.099, +0.019] n.s.

结论：
1. 在"选对原理"度量下三方无显著差异——与全部评委（含外部）的
   质量持平判定一致，进一步坐实 keyword −0.104 为度量伪影。
2. v5b 名义值最低（0.205），方向与评委读数一致但不显著；
   注入没有提升选理能力，也没有显著损害它。
3. 全体 F1 偏低（~0.25）主因是答案普遍"霰弹式"提及 ~10 个原理
   而参考仅 ~4 个——精确率被稀释；抽取器噪音对三臂对称，
   配对比较仍有效。benchmark v2 若采用此度量，需先收紧抽取器
   （如仅统计"原理N"显式编号与推荐理由段落的提及）。
