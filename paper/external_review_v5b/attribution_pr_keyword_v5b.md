## 结论：以测量伪影为主，非选理能力退化

1. **长度表面效应是主因**：v5b 每千字的关键词命中密度反而比 base 高 83%，
   绝对命中数下降完全由答案缩短（0.39×）解释；反事实分解显示长度贡献
   覆盖了全部净差。
2. **丢失的主要是通用框架词**（78%），即 base 长文自然撒落的"TRIZ/发明原理/
   技术矛盾"等词汇，commit-style 短答不再提及——词汇契约差异，非质量差异。
3. **原理选择差异是次因**（22%）：确有少量题目 v5b 推荐的原理不同于参考答案
   （如分割 vs 预先作用），属真实选理分歧，但量级不足以解释 −0.104。
4. judge 轨（含全部三个外部评委）判定 v5b 与 base 质量持平，
   与"伪影为主"的归因一致。

## 裁决含义

G7 按构造正确熔断（它不裁决真伪，只检测显著反向）；本归因将 G3 的
"真退化/伪影"判定落实为**以伪影为主**。但拒绝裁决维持不变——外部评委
未确认任何 judge 轨收益（+0.067/−0.003/+0.015 全 n.s.），keyword 契约
损失没有等价收益可交换。v5a 继续在位。
