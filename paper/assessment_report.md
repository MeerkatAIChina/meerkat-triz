## 一、执行摘要(一页)

**这次训练最重要的产出不是模型,而是一套被实战检验过的评测方法与三个可发表的测量学发现。**

1. **微调本身的质量结论是负的,且已证实。** 修复"base 输出被英文 think 草稿污染"的测量事故后,干净锚点下 v4−base judge 差从 +1.00 [0.80,1.19] **反转为 −0.30 [−0.46,−0.14] 显著为负**,v2−base 同为 −0.29 [−0.42,−0.16];关键词轨与 base 持平(−0.007,ns)(E0 §4.3)。微调的真实价值是**行为风格转换**:回答从长篇 think 式作答(均长 3250 字符)变为 ~1/10 长度(~300 字符)的直接作答,表层关键词覆盖不丢——这对产品体验是实的,但"绝对质量提升"的旧叙事不成立。
2. **三个方法学发现可发表,分量超预期:** ① 思考型模型空 think 块被剥离导致的基座污染(反号级后果);② pairwise judge 位置不一致率 **0.87**,为文献摆动量级的两倍多,双序合并为唯一有效口径;③ 关键词轨与 judge 轨只共享 ~10% 方差,迭代中真实发生过两轨显著反向(v3 vs v2),ARIZ 关键词漏判率 31.7%。
3. **发货判定:保留 v2。** v4≈v2(双轨均无显著差异),且 v4 的 concept_explanation 术语复诵真实退化(E2 终判:非噪声、非同义伪影,真缺失 8 词次)。决策门原判"保留 v2"在干净锚点下依然成立,但理由链已彻底改写。
4. **投稿路线:TMLR 或 ACL/EMNLP 评测类 workshop**,推荐题目《当基线在说谎……》(见 `paper_skeleton.md` §1)。三处干净 base 臂补跑已于 2026-07-23 回填完毕(E1a' 合并胜率 0.260 [0.204,0.325] 显著负 / E1b v4−base 32k −0.30 ✅ / E3' v4 vs base +0.083 ✅);还差:一个真异源评委终审、E4/E5 消融视审稿风险决定。

### 2.1 可发表的发现与分量

| 发现 | 证据等级 | 分量评估 |
|---|---|---|
| ① 思考型模型 think 块剥离致基座污染(诊断→修复→反号全链) | 【已证实】E0 终稿,+1.00→−0.30 反号 | **强**。随 thinking-native 模型普及,这是一类会被大量团队踩中的系统性陷阱;我们给出了根因(chat template 锚点丢失)、诊断矩阵(4 策略冒烟)与修复方案,可迁移性高 |

## 三、核心发现清单(E0–E3 全部)与工程启示

### E0 — base 锚点 think 污染修复【已证实,最重要】

- 现象:v4 金标评测中 base 91/100 题输出为未闭合英文 think 草稿(1024 token 预算烧光,正式答案从未产生);两轨评的都是草稿(`stats_review.md` §2.1)。
- 根因:`eval_harness.py:render_prompt` 在 `enable_thinking=False` 渲染后**剥掉了空 think 块**,thinking-native 基座失去"思考已结束"锚点,100/100 自吐英文草稿(E0 §2)。
- 修复后(E0 §4):干净 base judge 均值 2.87 / kw 0.5642(污染草稿为 1.57 / 0.3661);v4−base judge **−0.30 [−0.46,−0.14]**、v2−base judge **−0.29 [−0.42,−0.16]** 均显著为负;kw 轨双双 ns;McNemar 反方向显著(10/30, p=0.0022)。**原"+1.00 提升"系伪影。**
- 微调真实行为变化:长篇 think 式作答 → ~1/10 长度直接作答(3250 → ~300 字符),kw 覆盖持平。
- **工程启示 ①:harness 对 thinking-native 模型严禁剥离空 think 块;评测基座前必须做"输出结构完整性"冒烟(think 是否闭合、是否有正式答案、语言是否符合预期)。** 通用原则:凡输入含"base 对 100 金标题的回答"的分析,核对缓存 tag 不是 `base_goldfix` 之前一律视为受污染(E0 §5)。

### E1a — pairwise judge 极端第二位锚定【已证实(机制)/ 待验证(干净臂胜率)】

- AB 序 v4 胜率 0.180 [0.117,0.267] vs BA 序 0.800 [0.711,0.867];位置不一致率 **0.87** [0.79,0.92],硬翻转 0.77,B 位总胜率 0.81(`experiments/e1/e1_report.md`)。
- 双序合并 v4 胜率 0.49 ≈ 平局——**单序 pairwise 结论一律无效,双序合并是唯一有效口径**。
- 干净臂 E1a' 已补跑(v4 vs base_goldfix):双序合并 v4 胜率 **0.260 [0.204, 0.325]**——v4 显著输给干净 base,与污染臂合并 0.49 ≈ 平局形成鲜明对照;位置不一致率 **0.58**、B 位胜率 0.65——第二位锚定机制仍在,但幅度较污染臂(0.87/0.81)明显减弱。机制发现与锚点无关、稳健成立;v4 对 base 的胜率绝对值以干净臂为准。
- **工程启示 ②:一切 pairwise 评测必须 AB/BA 双序,报告合并胜率与位置不一致率;不一致率 >10% 时单序数字作废。**

### E1b — 跨评委一致性【已证实,但限于同族】

- moonshot-v1-32k vs moonshot-v1-8k(n=300):逐题 Spearman ρ=0.945,v4−base 差值符号一致率 0.94,排序一致(v2≈v4>base)(`experiments/e1/e1_report.md`)。
- 局限:kimi-k2-0711-preview 探测 404,兜底 8k 属"同族弱异源",不能排除家族级共享偏差(`experiments/STATE.md`)。干净 base 臂(E1b 补臂)已回填:base_goldfix 均分 2.87 > v2 2.58 ≈ v4 2.57;v4−base:moonshot-v1-32k **−0.30 [−0.46,−0.14] 显著为负**、moonshot-v1-8k −0.11,符号一致率 0.85;v2−base 32k −0.29 ✅,一致率 0.82;干净锚点下跨评委逐题 Spearman ρ=0.759。
- **工程启示 ③:评委稳健性声明必须标注评委家族谱系;"换了个同族小弟"不算异源验证。**

### E1c — judge 确定性与翻转率【已证实,独立可发表】

- **T=0 翻转率 0.000**(80 cell 全一致)——API 在该任务上完全确定,无需多次投票;T=0.7 翻转率 0.015,远低于文献 13.6%;k=3 多数表决一致率 0.988(`experiments/e1/e1_report.md`)。
- **工程启示 ④:T=0 + rubric 锚定下单次裁决即可信,不必浪费 API 做多次投票;但须每换一个 judge/任务重新验证确定性,不可默认。**

### E2 — concept_explanation 退化归因【已证实】

- 终判:**非噪声、非同义伪影**——v4 真缺失 TRIZ 工具术语言名(功能分析×3、Functionality、Cost、矛盾矩阵、S曲线等共 8 词次;synonym 伪影 0 条),但 judge 重判 v4 vs v2 +0.07 [−0.2,0.33] 持平、v4 vs base +1.2 [0.8,1.53] 显著为正(`experiments/e2/e2_report.json`)。
- 数据侧:cap 门"长答案优先"保留集显著更长(MWU p=5.3e-25)但幅度仅 +5%——方向显著、效应量小。
- 性质:术语表述层面的真实行为偏移(v4 倾向直接解释概念、不复诵工具箱术语),n=15 下决策门"保留 v2"稳健;**v5 修复方向 = CE 样本保留术语枚举式答案**。
- **工程启示 ⑤:数据质量门的排序规则(如"长答案优先")是训练信号,会写进模型行为;质量门变更须配子集级回归评测。**

### E3 — ARIZ 关键词伪影分离【已证实(漏判率)/ 待验证(干净 base 臂差值)】

- 关键词漏判率 **31.7%**(19/60,rubric≥0.5 而 kw<0.5),反向高估仅 1/60;漏判几乎全是"英文步骤名/同义表述"(`experiments/e3/e3_report.md` 漏判清单)。
- rubric 轨:v4 0.883 ≈ v2 0.875 > base(草稿)0.675;v4 vs v2 +0.008 [−0.083,0.125] 持平。**"v2 ARIZ 回退"在语义轨下消失,证实为关键词伪影**(与 W3 §5 三证据一致)。
- base 干净臂(E3')已重判:rubric 轨 base_goldfix **0.800** / v2 0.875 / v4 0.883;**v4 vs 干净 base +0.083 [0.033, 0.142] 显著**,v2 vs base +0.075 [−0.025, 0.15] 不显著;干净 base 关键词漏判仅 3/20(草稿臂为 19/60=31.7%)。v4 的 ARIZ 语义优势在干净锚点下依然显著,是最稳健的正面发现。
- **工程启示 ⑥:关键词轨对有显式过程结构的任务(ARIZ 六步)系统性低估同义表述;此类指标必须配 rubric 语义轨,漏判案例回流关键词别名表。**

### 贯穿性发现 — 双轨分歧与决策门

- eval2:v3 vs v2 关键词轨 +0.0556 [0.0010,0.1099] ✅ 与 judge 轨 −0.0682 [−0.1078,−0.0296] ✅ **结论相反**(`evidence_table.md` ②-C);gold 两轨逐题相关仅 r≈0.32(共享 ~10% 方差)(`stats_review.md` §3.1)。
- v3 的行为机制:judge 低分 + "仅 kw 过"31 题 → **v3 学会了堆关键词,语义质量反降**(`stats_review.md` §3.2)。
- **工程启示 ⑦(最重要的一条):发布/回滚决策门必须双轨化——单轨显著不得独立下判;两轨反向时默认回滚并启动归因实验(本项目的 E2/E3 正是这个流程)。**

## 四、对 v1–v4 的诚实判定

**结论:发货 v2。**

| 版本 | 判定 | 依据 |
|---|---|---|
| v1 | ❌ 淘汰 | 零质量门数据;overall −0.057、principle 0.9→0.6、ARIZ −0.111 整体回退(`results/METRICS_LEDGER.md:8`);eval2 中 general_probe 显著退化 −0.133 ✅(`evidence_table.md` ②-C) |
| **v2** | ✅ **发货** | 干净锚点下与 v4 等效(judge −0.01 [−0.13,+0.11],kw +0.008 ns,E0 §4.3);eval2 中 judge 轨显著优于(污染前的口径下)base +0.0736 ✅;ARIZ"回退"已被 E3 证为关键词伪影;相对 v4 多保留术语复诵行为(CE 子集 v4 −0.083 [−0.149,−0.023] 显著,E2) |
| v3 | ❌ 不发货 | 双轨分歧的反面教材:kw 轨上升系"堆关键词"行为,judge 轨 −0.0682 ✅ 显著恶化(`stats_review.md` §3.2);另曾发生全零 lora_B 发货事故(`evidence_table.md` ⑤-5) |
| v4 | ❌ 暂不替代 v2 | 管线最干净(七道质量门、completion-only loss、BF16),但干净锚点下 judge 显著低于 base(−0.30),替代条件不成立;CE 术语复诵真实退化(E2);与 v2 等效无增量(E0 §4.4) |

**必须向利益相关方澄清的一点**:v2 的"发货"含义是"行为风格转换器"——回答简洁 10 倍、直接作答、关键词水平持平,但 judge 轨质量**低于** verbose 的 base 约 0.29/4(7%)(E0 §4.5)。若产品 KPI 是"绝对答案质量超过 base",四个版本均未达成;若 KPI 是"简洁直接的专业作答体验",v2 达标。这个定位必须在任何对外叙事中说死,避免重现"+1.00"式的自我误导。

## 五、补充实验执行总结

### 5.1 做了什么、花了什么

| 实验 | 内容 | 成本 | 状态 |
|---|---|---|---|

| E1a | pairwise 位置交换双跑(200 裁决) | API ~20 min | ✅ 完成;干净臂 E1a' 已回填(合并胜率 0.260 [0.204,0.325]、不一致率 0.58) |
| E1b | 跨评委重判(300 裁决) | API ~25 min | ✅ 完成;干净臂已回填(v4−base 32k −0.30 ✅、8k −0.11,一致率 0.85) |
| E1c | 翻转率(800 裁决,T=0/T=0.7 双组) | API ~55 min | ✅ 完成 |
| E2 | CE 退化归因(数据分析 + 15 题 judge 重判 + 关键词重分类) | CPU ~1h + API ~10 min | ✅ 完成 |
| E3 | ARIZ rubric 重判(60 裁决)+ 漏判清单 | API ~10 min | ✅ 完成;干净臂 E3' 已回填(v4 vs base +0.083 [0.033,0.142] ✅) |

P0 包(E1a/b/c+E2+E3)合计约 1,500 次裁决 / ~300 请求,RPM=3 下纯等待 ~2.5h,零 GPU(`experiment_plan.md` §4.1);E0 另有 GPU 生成与统计复算。总成本:一个工作日内的 API 费用 + 少量 GPU 小时——**以极小代价推翻了一个会写进论文的错误主结论,ROI 极高。**
