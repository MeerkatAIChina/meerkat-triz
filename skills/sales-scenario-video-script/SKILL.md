# 销售场景化卖点视频拍摄Skill

基于**销售流程四步法**（让客户喜欢你→挖场景找痛点→立价值带体验→促成交解抗拒），将产品卖点转化为**场景化视频拍摄脚本**的完整方法论。

> 本Skill适用于全品类消费品；文中高频场景库、卖点矩阵与脚本案例以出行类产品为例，使用时按自身品类替换。

---

## 核心理念

### 为什么做场景化卖点视频？

| 传统产品视频 | 场景化卖点视频 |
|-------------|---------------|
| 讲参数、讲配置 | 讲场景、讲痛点 |
| 用户记不住 | 用户有共鸣 |
| 看完就忘 | 看完想买 |
| 自嗨型内容 | 转化型内容 |

### 视频类型定位

本Skill专注于制作**销售导向的短视频**，用于：
- 销售顾问朋友圈/抖音/视频号发布
- 门店引流获客
- 客户到店前的预热教育
- 体验后的价值强化

### 销售流程与视频脚本映射

```
销售流程四步法              视频内容矩阵
─────────────────────────────────────────────
01 让客户喜欢你      →    人设建立类视频
02 挖场景找痛点      →    痛点共鸣类视频  
03 立价值带体验      →    卖点演示类视频
04 促成交解抗拒      →    异议处理类视频
```

## 第一步：场景化卖点提炼（核心输入）

### 1.1 场景化卖点提炼表格

在使用本Skill前，必须先完成**场景化卖点提炼**，将产品卖点与具体场景进行匹配。这是生成视频脚本的基础输入。

#### 场景定义公式
```
完整场景 = 时间 + 地点 + 人物 + 做什么 + 痛点/爽点
```

#### 高频场景库（参考，痛点与卖点列以出行类产品为例，六大场景类型跨品类通用）

| 场景类型 | 具体场景 | 对应痛点 | 可拍摄卖点 |
|---------|---------|---------|-----------|
| **日常通勤** | 早高峰堵车、加班夜归 | 累、烦、不安全 | 智驾辅助、舒适性、安全性 |
| **周末出游** | 短途自驾、露营野餐 | 空间不够、续航焦虑 | 续航、空间、外放电 |
| **家庭出行** | 接送孩子、三代同游 | 安全担忧、孩子哭闹 | 安全、空间、娱乐系统 |
| **商务场景** | 客户接待、商务洽谈 | 面子不够、不够安静 | 豪华感、静谧性、后排舒适 |
| **社交展示** | 朋友聚会、约会出行 | 没个性、不够酷 | 颜值、科技感、独特设计 |
| **极限挑战** | 长途自驾、恶劣天气 | 怕抛锚、不敢开 | 续航、可靠性、四驱 |

#### 场景化卖点提炼输出表

### 1.2 场景挖掘方法论

**如何挖掘有效场景？**

#### 四维度探询法

| 维度 | 探询问题 | 示例（示例车型） |
|-----|---------|--------------|
| **时间** | 什么时候用？ | 早高峰送娃、周末出游、雨天出行 |
| **地点** | 在哪里用？ | 学校门口、商场停车场、小区道路 |
| **人物** | 谁在使用？ | 宝妈+孩子、宝妈+老人+孩子 |
| **做什么** | 使用时做什么？ | 接送、购物、装载物品、哄孩子 |

#### 场景痛点提炼法

**从场景到痛点的推导路径：**
```
场景描述 → 用户任务 → 遇到的阻碍 → 情绪感受 → 痛点定义
```

**示例：**
```
场景：雨天下午，学校门口，宝妈接孩子放学
任务：安全快速接到孩子并回家
阻碍：雨帘乱飞遮挡视线、车内起雾看不清路
情绪：焦虑、担心安全
痛点：雨天骑行视线差、安全隐患大
```

### 1.3 卖点-场景匹配原则

| 原则 | 说明 | 示例 |
|-----|------|------|
| **高频优先** | 选择用户最常遇到的场景 | 每天接送孩子 > 偶尔长途出游 |
| **高痛优先** | 选择痛点最强烈的场景 | 安全担忧 > 颜色不喜欢 |
| **可视优先** | 选择容易拍摄呈现的场景 | 倒车演示 > 底盘结构 |
| **差异优先** | 选择能体现产品差异的场景 | 三碟刹制动 > 普通刹车 |

## 第二步：视频类型选择

### 2.1 四种视频类型定义

根据销售流程四步法，设计四种视频类型：

| 视频类型 | 销售阶段 | 目的 | 时长 | 发布场景 | 内容重点 |
|---------|---------|------|------|---------|---------|
| **人设建立型** | 第一步 | 让客户喜欢你 | 30-60秒 | 日常朋友圈 | 专业人设+信任背书 |
| **痛点共鸣型** | 第二步 | 挖场景找痛点 | 45-90秒 | 精准投放 | 场景痛点+情感共鸣 |
| **卖点演示型** | 第三步 | 立价值带体验 | 60-120秒 | 体验/试驾前后 | FABE展示+场景体验 |
| **异议处理型** | 第四步 | 促成交解抗拒 | 45-90秒 | 客户犹豫时 | 专业解答+案例佐证 |

### 2.2 视频类型与场景化卖点表的对应

**根据场景化卖点表，为每个卖点匹配视频类型：**

```markdown
## 视频类型分配表

| 场景化卖点表序号 | 场景类型 | 核心卖点 | 建议视频类型 | 优先级 |
|----------------|---------|---------|-------------|-------|
| 1 | 日常通勤-安全 | 强化车架+三碟刹 | 痛点共鸣型 | P0 |
| 2 | 家庭出行-智能 | 智能互联+倒车影像 | 卖点演示型 | P0 |
| 3 | 周末出游-空间 | 多重储物空间 | 卖点演示型 | P1 |
| 4 | 日常通勤-舒适 | 除雾暖风机 | 痛点共鸣型 | P1 |
| 5 | 社交展示-颜值 | 汽车级外观 | 人设建立型 | P2 |
```

## 第三步：视频脚本结构设计

### 3.1 通用脚本结构（AIDA模型）

所有视频脚本遵循AIDA结构：

```
A - Attention（引起注意）→ 开场钩子（3-5秒）
I - Interest（激发兴趣）→ 痛点共鸣（15-30秒）
D - Desire（刺激欲望）→ 卖点演示（30-60秒）
A - Action（促成行动）→ 引导转化（5-10秒）
```

### 3.2 分镜脚本模板

```markdown

### 基础信息
- 视频类型：
- 目标人群：
- 核心卖点：（引用场景化卖点表中的对应卖点）
- 拍摄场景：（引用场景化卖点表中的时间+地点）
- 预计时长：

### 分镜脚本

| 镜号 | 时长 | 画面内容 | 景别 | 拍摄角度 | 口播/字幕 | 音效/音乐 |
|-----|------|---------|------|---------|----------|----------|
| 01 | 3s | | 特写 | | | |
| 02 | 5s | | 中景 | | | |
| ... | | | | | | |

### 拍摄要点
- 场景布置：（对应场景化卖点表中的地点）
- 演员要求：（对应场景化卖点表中的人物）
- 道具准备：（对应场景化卖点表中的做什么）

### 发布建议
- 发布时间：
- 话题标签：
- 引流钩子：
```

## 第四步：四类视频脚本生成

### 4.1 人设建立型视频（让客户喜欢你）

**目的**：建立销售顾问专业、可信、亲和的人设

**结构**：
```
开场（3s）：打招呼+身份介绍
共鸣（10s）：说出用户心声
价值（15s）：我能帮你解决什么
信任（10s）：案例/数据背书
引导（5s）：关注/私信
```

**脚本模板**：

```markdown
## 人设建立型视频脚本

### 【开场】（3秒）
**画面**：销售顾问微笑面对镜头，背景是展厅/车内
**口播**："嗨，我是[姓名]，在[品牌]做销售顾问[年限]年了。"
**字幕**：[姓名] | [品牌]销售顾问

### 【共鸣】（10秒）
**画面**：切换客户纠结的画面（可用素材/情景再现）
**口播**："我发现很多客户选产品时特别纠结，参数看了无数，比较了好几款，还是不知道选哪个。"
**字幕**：选择纠结症

### 【价值】（15秒）
**画面**：销售顾问自信讲解，配合手势
**口播**："其实买车没那么复杂，关键是找到适合你的。我帮[数字]+客户选到了心仪的产品，总结了一套方法..."
**字幕**：[数字]+客户的选择

### 【信任】（10秒）
**画面**：展示客户好评截图/交车照片（快速闪过）
**口播**："不推销，只推荐。关注我，选购少踩坑。"
**字幕**：不推销，只推荐

### 【引导】（5秒）
**画面**：销售顾问指向评论区/私信按钮
**口播**："有选购问题，评论区留言，我一个个回。"
**字幕**：评论区见
```

---

### 4.2 痛点共鸣型视频（挖场景找痛点）

**目的**：通过场景痛点引发用户共鸣，建立需求

**结构**：
```
钩子（5s）：痛点场景切入
放大（20s）：痛点细节描述
共鸣（15s）：说出用户心里话
转折（5s）：引出卖点
```

**脚本模板**：

```markdown
## 痛点共鸣型视频脚本

### 【钩子】（5秒）
**画面**：具体痛点场景（引用场景化卖点表中的时间+地点+人物+做什么）
**口播**："有没有遇到过这种情况？[场景化描述]..."
**字幕**：[痛点关键词]

### 【放大】（20秒）
**画面**：多角度展示痛点场景
**口播**："[痛点细节1]，[痛点细节2]，[痛点细节3]。一路下来，[情绪描述]。"
**字幕**：
- [痛点1] → [后果1]
- [痛点2] → [后果2]
- [痛点3] → [后果3]

### 【共鸣】（15秒）
**画面**：销售顾问理解地点头
**口播**："很多[人物]跟我说，[共鸣话术]。其实，[转折话术]。"
**字幕**：[情感共鸣点]

### 【转折】（5秒）
**画面**：展示解决方案（产品外观）
**口播**："看看这款产品是怎么解决这些问题的..."
**字幕**：下集揭晓
```

### 4.3 卖点演示型视频（立价值带体验）

**目的**：通过场景化演示，让用户感知卖点价值

**结构**：
```
开场（5s）：场景引入
痛点（10s）：回顾用户痛点
演示（60s）：FABE结构展示卖点
证据（15s）：数据/案例/体验
引导（10s）：预约试驾/到店
```

**脚本模板**：

```markdown
## 卖点演示型视频脚本

### 【开场】（5秒）
**画面**：使用场景（引用场景化卖点表中的完整场景）
**口播**："[场景描述]，最怕什么？"
**字幕**：[场景关键词]

### 【痛点】（10秒）
**画面**：展示常见痛点画面
**口播**："[痛点1]，[痛点2]，[痛点3]。"
**字幕**：[痛点总结]

### 【演示-F】（15秒）
**画面**：展示产品特性
**口播**："看看[产品]的[卖点F特性]。我们采用了[技术/设计]，实现了[具体参数]。"
**字幕**：F-特性：[一句话概括]

### 【演示-A】（15秒）
**画面**：与竞品/行业对比
**口播**："相比同级别产品，我们的[卖点A优势]。行业平均是[数据]，我们做到了[数据]。"
**字幕**：A-优势：[对比数据]

### 【演示-B】（20秒）
**画面**：用户使用场景（引用场景化卖点表中的场景）
**口播**："这意味着什么？[场景化描述用户利益]。比如[具体场景]，你可以[做什么]，[带来什么好处]。"
**字幕**：B-利益：[场景化描述]

### 【演示-E】（10秒）
**画面**：展示证据（证书/数据/用户证言）
**口播**："这不是我说的，[证据内容]。"
**字幕**：E-证据：[一句话]

### 【引导】（10秒）
**画面**：销售顾问邀请手势
**口播**："百闻不如一试，点击链接预约体验，亲自感受一下。"
**字幕**：点击预约体验
```

### 4.4 异议处理型视频（促成交解抗拒）

**目的**：提前处理常见抗拒，降低用户决策门槛

**结构**：
```
开场（5s）：直接抛出抗拒
认同（10s）：先认同用户感受
解答（30s）：专业解答+证据
案例（15s）：真实案例佐证
引导（10s）：消除顾虑，促成行动
```

**脚本模板**：

```markdown
## 异议处理型视频脚本

### 【开场】（5秒）
**画面**：销售顾问面对镜头，表情认真
**口播**："有人说，[常见抗拒]。"
**字幕**："[抗拒内容]"

### 【认同】（10秒）
**画面**：销售顾问点头表示理解
**口播**："我理解这个顾虑，很多客户一开始也有同样的担心。毕竟[认同理由]。"
**字幕**：理解你的顾虑

### 【解答】（30秒）
**画面**：展示相关证据/数据/对比
**口播**："但实际情况是[专业解答]。我们[具体做法/数据]，所以[结论]。"
**字幕**：
- 事实：[关键事实]
- 数据：[支撑数据]
- 结论：[打消顾虑]

### 【案例】（15秒）
**画面**：展示真实客户案例（可匿名）
**口播**："比如我之前的客户[化名]，一开始也担心[抗拒]，后来[转折]，现在[结果]。"
**字幕**：真实客户案例

### 【引导】（10秒）
**画面**：销售顾问自信微笑
**口播**："顾虑是难免的，亲自试过才有答案。私信我，安排体验，用体验说话。"
**字幕**：私信预约体验
```

## 第五步：拍摄执行指南

### 5.1 拍摄前准备清单

```markdown
## 拍摄准备清单

### 场景布置（对应场景化卖点表）
- [ ] 产品清洁（内外）
- [ ] 场景地点确认（引用场景化卖点表中的地点）
- [ ] 灯光设备（自然光优先）
- [ ] 收音设备（确保音质清晰）

### 道具准备（对应场景化卖点表中的"做什么"）
- [ ] 儿童安全座椅/安全带（家庭出行场景）
- [ ] 行李/物品（装载场景）
- [ ] 手机（展示APP功能）
```

## 使用提示

1. **必须先完成场景化卖点提炼表**，这是生成视频脚本的基础输入
2. **场景要真实可拍摄**，避免过于抽象的描述
3. **口播要口语化**，像跟客户聊天一样自然
4. **发布后及时跟进数据**，根据反馈优化脚本
5. **建议每个卖点生成1-2个视频**，形成内容矩阵
