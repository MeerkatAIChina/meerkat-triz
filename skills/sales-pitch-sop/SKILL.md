# 销售流程卖点话术Skill（优化版）

基于某头部两轮车企王牌导购训练营方法论，将**用户输入的产品卖点**转化为标准化销售流程SOP。适用于全品类消费品（家电、美妆、食品、服饰、出行工具等）的门店与线上销售；文中场景探询表、试驾触点等以出行类产品为例，使用时按自身品类替换。

---

## 核心理念

### 身份转变：从推销员到购买顾问

| 推销员 | 购买顾问 |
|-------|---------|
| 关注产品 | 关注客户 |
| 强调价格 | 塑造价值 |
| 将产品卖给客户 | 帮助客户买产品 |

### 客户购买八阶段

```
01满足 → 02认知 → 03决定 → 04方案 → 05标准 → 06评估 → 07选择 → 08后悔
```

**销售流程对应**:
- 01-02阶段：让客户喜欢你（建立信赖感）
- 03-04阶段：挖场景找痛点（了解需求）
- 05-06阶段：立价值带体验（塑造价值）
- 07-08阶段：促成交解抗拒（促成成交）

### 王牌导购销售流程

| 步骤 | 名称 | 分值 | 核心动作 |
|-----|------|------|---------|
| 01 | 让客户喜欢你 | 40分 | 建立信赖感 |
| 02 | 挖场景找痛点 | 30分 | 了解需求 |
| 03 | 立价值带体验 | 20分 | 塑造价值 |
| 04 | 促成交解抗拒 | 10分 | 促成成交 |

## 第一步：让客户喜欢你（建立信赖感）40分

### 核心原则
**你不会和你不喜欢的人买东西**

### 关键动作SOP

#### 1.1 4S瞬间亲和力（30秒）

| 要素 | 动作 | 标准 |
|-----|------|------|
| **See 看** | 目光接触 | 微笑注视客户，眼神真诚 |
| **Smile 微笑** | 自然微笑 | 发自内心的友好笑容 |
| **Shake 握手/挥手** | 适当肢体接触 | 热情握手或挥手示意 |
| **Speak 问好** | 主动问候 | "您好，欢迎光临！" |

**标准话术**:
> "您好，欢迎光临！我是销售顾问[姓名]，看产品是吧？外面挺热的/冷的，先给您倒杯水。"

#### 1.2 寒暄破冰（2-3分钟）

**聊一些与产品无关的事情**:
- 天气、交通
- 孩子（如果带孩子来）
- 当前使用情况

**标准话术**:
> "看您挺面善的，之前来过咱们店吗？"  
> "您是怎么过来的？路上还顺利吧？"  
> "看您带着孩子，是给家里选东西吧？"

#### 1.3 背景探测-黄金三问（2分钟）

| 问题 | 目的 | 话术 |
|-----|------|------|
| **黄金一问** | 了解使用人 | "平时这产品主要谁用？" |
| **黄金二问** | 了解使用场景 | "这产品平时主要做什么用？" |
| **黄金三问** | 了解需求痛点 | 更新："您之前用的产品，哪里不满意？"  
首购："您选产品，会比较看重哪些？" |

#### 1.4 建立信赖感-四大支柱

**信赖感清单**:

| 支柱 | 建立方式 | 具体内容 |
|-----|---------|---------|
| **品牌** | 实力、荣誉、数据、背书 | 根据输入的品牌信息介绍 |
| **老客户** | 好评、照片、视频、案例 | 准备客户好评截图、案例 |
| **顾问本身** | 真诚、专业、服务 | 帮客户买东西、先左后右、先慢后快 |
| **产品本身** | 解决的核心问题、创造的核心价值 | 根据输入的卖点介绍 |

## 第二步：挖场景找痛点（了解需求）30分

### 核心原则
**人不痛苦，不会改变**

### 关键动作SOP

#### 2.1 聆听技巧

| 技巧 | 动作 | 目的 |
|-----|------|------|
| **情绪同步** | 认同客户感受 | 建立共鸣 |
| **鼓励多说** | 点头、"嗯"、"对的" | 让客户多表达 |
| **眼神注视** | 真诚注视客户 | 表示关注 |
| **重复确认** | 重复客户关键词 | 确认理解正确 |

#### 2.2 场景探询

**什么是场景？**
- 时间、地点
- 人物
- 做什么

**根据产品类别设计探询问题**（下表以出行类产品为例，其他品类按高频使用场景替换）:

| 产品类别 | 高频场景 | 探询问题 |
|---------|---------|---------|
| **家庭用车** | 接送孩子、买菜购物、周末出游 | "您每天接送孩子多远？" / "周末会带孩子出去玩吗？" |
| **通勤代步** | 日常上下班、短途出行 | "您每天通勤多远？路上堵不堵？" |
| **商用/工具** | 拉货、运输、工作使用 | "您平时主要拉什么货？大概多重？" |
| **老年/休闲** | 买菜、公园、接送孙辈 | "您平时主要去哪里？路程远吗？" |

#### 2.3 痛点深挖

**根据输入的产品卖点，反向推导客户痛点**:

| 产品卖点 | 对应客户痛点 | 深挖问题 |
|---------|------------|---------|
| [输入的卖点1] | [推导的痛点1] | "您是不是担心/觉得...？" |
| [输入的卖点2] | [推导的痛点2] | "您是不是担心/觉得...？" |
| [输入的卖点3] | [推导的痛点3] | "您是不是担心/觉得...？" |

**痛点确认话术**:
> "听您这么说，最头疼的是[痛点]，对吧？这个确实挺影响使用体验的。"

#### 2.4 痛点打分排序

| 痛点 | 很痛吗(1-9) | 很多人痛吗(1-9) | 经常痛吗(1-9) | 排序 | 对应产品卖点 |
|-----|------------|----------------|--------------|------|-------------|
| [痛点1] | | | | P0 | [卖点X] |
| [痛点2] | | | | P1 | [卖点Y] |

## 第三步：立价值带体验（塑造价值）20分

### FABE价值塑造法

| 维度 | 含义 | 应用 |
|-----|------|------|
| **F-Feature（属性）** | 产品的物理、化学、生物、经济等特征 | 根据输入的技术参数 |
| **A-Advantage（优势）** | 和同类产品相比较的优势 | 对比竞品 |
| **B-Benefit（价值）** | 产品的优势给客户带来的好处 | 解决客户痛点 |
| **E-Evidence（证据）** | 第三方见证、五感体验 | 数据、案例、体验 |

### 根据输入卖点进行FABE包装

**针对每个输入的卖点，按FABE法则包装**:

#### 卖点1: [输入的卖点名称]

**F - 特性 (Feature)**
- 技术参数: [根据输入填写]
- 技术原理: [根据输入推导，≥150字]
- 设计灵感: [根据输入推导，≥150字]

**A - 优势 (Advantage)**
- 与行业对比: [行业水平]
- 与竞品对比: [竞品差异，根据输入的竞品信息]
- 技术突破: [创新点]

**B - 利益 (Benefit)**
- 用户利益: [解决客户什么痛点]
- 场景价值: [在什么场景下有用]
- 情感价值: [带来什么感受]

**E - 证据 (Evidence)**
- 数据支撑: [具体数据]
- 权威认证: [认证/奖项]
- 用户证言: [真实反馈]

**一句话话术**: [销售话术]

### 店内体验设计（边做边说）

**根据输入的产品卖点，设计对应的体验动作**:

| 体验编号 | 对应卖点 | 体验动作 | 口播话术 |
|---------|---------|---------|---------|
| 演示1 | [卖点X] | [具体动作] | "您[动作]，感受一下[卖点]..." |
| 演示2 | [卖点Y] | [具体动作] | "您[动作]，感受一下[卖点]..." |
| 演示3 | [卖点Z] | [具体动作] | "您[动作]，感受一下[卖点]..." |
| 演示4 | [卖点W] | [具体动作] | "您[动作]，感受一下[卖点]..." |

**演示结束一定接一句体验邀请**:
> "静态看是一回事，您等会儿自己[体验动作]，感觉会更明显。"

### 试用/试驾体验设计（按触点走）

**根据产品特性设计体验触点**（下表以出行类产品试驾为例；美妆为试妆、食品为试吃、服饰为试穿，按品类替换）:

| 触点 | 体验内容 | 让客户感受 | 导购提示 |
|-----|---------|-----------|---------|
| **01起步** | 起步平顺性 | 起步顺不顺、心里稳不稳 | "您先别跑快，先感受起步顺不顺..." |
| **02加速** | 动力响应 | 加速快不快、有没有力 | "您轻踩一下，感受一下加速..." |
| **03过坑** | 减震舒适性 | 过坑颠不颠、后排跳不跳 | "您特意压一下，感受是不是那种硬碰硬的颠..." |
| **04拐弯** | 操控稳定性 | 拐弯慌不慌、车飘不飘 | "您轻轻拐一下弯，感受心里发不发慌..." |
| **05坡道** | 坡道性能 | 停得住、起得稳 | "坡上停一下再起一下，看看慌不慌..." |
| **06倒车** | 视野/辅助 | 看得清、倒得准 | "您试一下[倒车辅助功能]，感受下是不是更踏实..." |
| **07静音** | NVH性能 | 噪音大不大、安静与否 | "您注意听，这个速度下噪音控制怎么样..." |

**体验前固定四句**:
1. 先感受
2. 再对比
3. 重点试[根据产品卖点确定重点，如：过坑和拐弯/加速和静音]
4. 值不值是试出来的

### 体验后确认+顺势成交

**体验后确认话术（根据产品卖点设计）**:

| 确认问题 | 对应卖点 | 话术 |
|---------|---------|------|
| 刚才[体验点]，是不是[感受]？ | [卖点X] | "刚才[动作]那一下，是不是[正面感受]？" |
| [功能/配置]，是不是[感受]？ | [卖点Y] | "[功能]这一[眼/下]，是不是明显[正面感受]？" |
| 这产品是不是[总结性感受]？ | 整体 | "这产品是不是不只是[卖点A]，而且[卖点B]、更[卖点C]？" |

**顺势成交话术**:
> "您现在担心的，其实已经不是这产品好不好，而是今天定哪款更合适。"  
> "现在把单开了，[交付条件]，您直接就能用。"

## 第四步：促成交解抗拒（促成成交）10分

### 三种成交技巧

#### 技巧1：假设成交法（一直犹豫，临门一脚）

**适用场景**: 客户已经明显认可产品，只差最后一脚

**客户表现**:
- 频繁点头
- 主动看颜色、看价格、问交付
- 家人也比较认可

**话术模板**:
> "您看这款产品更适合选[选项A]，还是[选项B]？"  
> "您今天定的话，我给您[优惠A]，还是[优惠B]？"  
> "您是[付款方式A]方便，还是[付款方式B]方便？我这边先给您把单开起来。"  
> "这款产品您已经体验出来了，接下来咱们就别纠结买不买了，看看[下一步动作]。"

#### 技巧2：三句话成交（一直犹豫）

**话术结构**:
1. **第一句：回到客户场景**
   > "您这款产品主要就是[客户说的使用场景]，对吧？"

2. **第二句：锁定刚才试出来的价值**
   > "刚才您也体验出来了，这款产品的[卖点A]、[卖点B]这些，确实比[竞品/现状]更[优势]。"

3. **第三句：自然推进成交**
   > "那其实这款产品就是更适合您现在的用法，咱们今天把[配置/颜色/款式]定下来就行了。"

#### 技巧3：分解觉得成交（我还得再想想）

**话术模板**:
> "您现在主要纠结的是[疑虑A]，还是[疑虑B]？"  
> "如果不考虑[疑虑]，单看使用，您觉得这款产品适不适合您？"  
> "那现在其实不是买不买的问题，是今天定，还是[替代方案]，对吧？"  
> "那咱们先把[产品/颜色/款式]定住，[其他事项]这块我再帮您看最方便的。"

### 常见抗拒解除

**根据产品卖点准备对应的抗拒解除话术**:

| 常见抗拒 | 客户真正顾虑 | 回应策略 | 推进句 |
|---------|------------|---------|--------|
| 嫌贵 | 怕花得不值 | 从价格拉回"值不值"，强调[核心卖点]的价值 | 咱们现在看的不是便不便宜，而是值不值 |
| 我再看看 | 还有顾虑没过 | 先问还想看什么，针对性解决 | 您现在主要是还想再比比，还是还有哪个点没过 |
| 回去商量 | 需要带信息回去 | 帮客户梳理重点，准备说服家人的话术 | 我先帮您把回去要说的重点理清 |
| 别家也有 | 担心买错 | 拉回具体场景对比[差异化卖点] | 真正要比的是[场景]这些时候 |
| 旧的还能用 | 觉得没必要换 | 区分"能用"和"更适合"，强调[升级卖点] | 不是换掉坏的，是把[痛点]换掉 |
| 功能太多 | 怕复杂、怕浪费 | 把功能翻成场景价值，强调[核心功能]的实用性 | 不是功能多，而是[场景]时真能帮上忙 |

## 使用流程

### Step 1: 准备输入信息
