# 加工访谈笔录Skill

> 将原始访谈笔录转化为结构化洞察，输出访谈小结和用户心智地图。适用于所有消费品品类的用户访谈加工，文中示例保留行业原样仅供示范。

## 一、Skill概述

### 1.1 功能定位

本Skill用于加工消费者访谈笔录，输出三份核心内容：

| 输出物 | 格式 | 用途 |
|--------|------|------|
| 访谈小结 | Markdown/Word | 快速汇报、团队共享 |
| 用户心智地图（表格版） | Excel | 数据分析、量化统计 |
| 用户心智地图（可视化版） | HTML | 演示汇报、直观展示 |

### 1.2 输入要求

- 输入格式：原始访谈笔录（文字稿/录音转文字）
- 访谈类型：深度访谈、焦点小组、用户观察等
- 访谈主题：消费行为、产品使用、购买决策等

### 1.3 处理流程

```
访谈笔录输入
    │
    ▼
┌─────────────────────────────────────┐
│  第一步：内容清洗与结构化              │
│  - 去除口语化表达                      │
│  - 分段标记（场景/行为/感受/需求）      │
│  - 提取关键引语                        │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  第二步：生成访谈小结                  │
│  - 按模板结构填充内容                  │
│  - 提炼核心发现                        │
│  - 总结用户洞察                        │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  第三步：构建用户心智地图              │
│  - 识别行为模式                        │
│  - 提取决策因子                        │
│  - 绘制心智模型                        │
└─────────────────────────────────────┘
    │
    ▼
输出：访谈小结 + Excel心智地图 + HTML可视化
```

## 二、第一步：内容清洗与结构化

### 2.1 清洗规则

| 清洗项 | 处理方式 | 示例 |
|--------|---------|------|
| 语气词 | 删除 | "嗯...那个...我觉得" → "我觉得" |
| 重复表述 | 合并 | "就是就是" → "就是" |
| 无关闲聊 | 删除 | 寒暄、跑题内容 |
| 时间标记 | 保留 | [10:23] 用于定位 |
| 关键引语 | 标记 | "原文引用" |

### 2.2 结构化标记

使用以下标签对内容进行结构化：

- 分段标记：**场景 / 行为 / 感受 / 需求**
- 提取关键引语（选择最有代表性的1-3句，原文引用）

## 三、第二步：生成访谈小结

### 3.1 访谈小结模板结构（猫鼬工厂版）

- 【背景信息】用户基本信息、使用场景
- 【行为描述】具体做了什么、如何做
- 【情感表达】感受、情绪、态度
- 【需求痛点】遇到的问题、未满足的需求
- 【决策因子】影响决策的关键因素
- 【期望建议】用户的期待和改进建议

### 3.3 60分钟加工流程（猫鼬工厂标准）

| 时间 | 任务 | 原则 |
|------|------|------|
| 0-10min | 通读访谈录音/笔记，标出3个highlight | 不要逐句整理 |
| 10-25min | 填写「我们访谈了谁」和「主要信息」 | 用bullet，不用完整句子 |
| 25-40min | 提炼1-3个Key Aha Moment | 必须有冲突性或反直觉 |
| 40-55min | 对应写出「对创新的启发」 | 每个Aha必须对应一个Inspiration |
| 55-60min | 快速检查，补充访谈流程调整建议 | 如有 |

### 3.4 填充指南

| 章节 | 填充要点 | 字数建议 |
|------|---------|---------|
| 我们访谈了谁 | 突出与主题相关的背景标签 | 100-150字 |
| 主要信息 | 客观描述，用bullet点 | 每点10-20字 |
| Key Aha Moment | 必须有冲突/反直觉，配原话 | 每点150-200字 |
| 对创新的启发 | 每个Aha对应具体创新机会 | 每点100-150字 |
| 关键引语 | 选择最有代表性的1-3句 | 原文引用 |

## 四、第三步：构建用户心智地图

### 4.1 用户心智地图框架

基于《用户行为分析》方法论——客户需求地图，心智地图包含以下7个层级：

```
客户需求地图（从上至下）
┌─────────────────────────────────────────┐
│  第一层：价值观（WHO）                    │
│  → 用户是谁？核心信念与追求               │
├─────────────────────────────────────────┤
│  第二层：心理意义（WHY）                  │
│  → 为什么需要？产品对用户的心理价值        │
├─────────────────────────────────────────┤
│  第三层：场景化任务（WHEN & WHERE）       │
│  → 何时何地？具体使用场景与任务           │
├─────────────────────────────────────────┤
│  第四层：判别标准（HOW）                  │
│  → 如何判断？用户的选择标准与决策逻辑      │
├─────────────────────────────────────────┤
│  第五层：情绪（Emotion）                  │
│  → 感受如何？使用过程中的情绪体验          │
├─────────────────────────────────────────┤
│  第六层：成果（Outcome）                  │
│  → 得到什么？实际获得的结果与收益          │
├─────────────────────────────────────────┤
│  第七层：五感（Sensory）                  │
│  → 感官体验？视觉/听觉/触觉/嗅觉/味觉      │
└─────────────────────────────────────────┘
```

分析逻辑：从上至下是需求拆解，从下至上体验验证。

各层级详解：

| 层级 | 核心问题 | 分析要点 | 输出形式 |
|------|---------|---------|---------|
| 价值观 | 用户是谁？ | 生活方式、价值追求、身份认同 | 用户画像描述 |
| 心理意义 | 为什么需要？ | 产品代表什么、满足什么心理需求 | 价值主张映射 |
| 场景化任务 | 何时何地用？ | 具体场景、任务流程、使用频次 | 场景-任务矩阵 |
| 判别标准 | 如何选择？ | 决策因子、优先级、对比维度 | 决策权重表 |
| 情绪 | 感受如何？ | 情绪类型、触发点、强度变化 | 情绪曲线图 |
| 成果 | 得到什么？ | 功能成果、情感成果、社交成果 | 成果清单 |
| 五感 | 感官体验？ | 视觉/听觉/触觉/嗅觉/味觉体验 | 五感评分表 |

### 4.2 Excel心智地图模板

基于客户需求地图的7层结构，设计4个Sheet（示例行以汽车产品访谈为示范，方法适用于所有消费品品类，按实际访谈内容填写）：

**Sheet 1：客户需求地图主表**

| 层级 | 维度 | 用户原话/观察 | 提炼洞察 | 业务启示 |
|------|------|--------------|---------|---------|
| 价值观 | 身份认同 | "我买特斯拉是觉得有科技感" | 追求科技先锋形象 | 强调科技属性 |
| 心理意义 | 情感价值 | "它代表我的品味" | 身份象征需求 | 打造品牌调性 |
| 场景化任务 | 具体场景 | "每天上下班开，周末带娃" | 通勤+家庭双重场景 | 场景化营销 |
| 判别标准 | 选择标准 | "先看续航，再看智能化" | 续航是首要标准 | 突出续航优势 |
| 情绪 | 情感体验 | "每次OTA升级都很惊喜" | 期待与惊喜感 | 持续迭代体验 |
| 成果 | 实际收益 | "省油钱，还能自动驾驶" | 经济+便利双重收益 | 量化价值呈现 |
| 五感 | 感官体验 | "外观很未来感，静音好" | 视觉+听觉优势 | 设计+NVH优化 |

**Sheet 2：场景-任务-情绪矩阵**

| 场景 | 任务 | 行为 | 情绪前 | 情绪后 | 痛点 | 期望 |
|------|------|------|--------|--------|------|------|
| 早晨通勤 | 开车上班 | 手机解锁上车 | 平常 | 方便 | 找钥匙麻烦 | 无感解锁 |
| 高速驾驶 | 长途出行 | 开启自动驾驶 | 紧张 | 省心 | 驾驶疲劳 | 完全自动驾驶 |
| 充电时 | 补充电量 | 找充电桩充电 | 焦虑 | 惊喜 | 充电慢/排队 | 超快充 |

**Sheet 3：决策因子权重分析**

| 决策因子 | 所属层级 | 权重(1-5) | 提及次数 | 正向 | 负向 | 典型引语 |
|---------|---------|----------|---------|------|------|---------|
| 品牌科技感 | 价值观 | 5 | 12 | 10 | 2 | "特斯拉代表未来" |
| 续航里程 | 判别标准 | 5 | 15 | 8 | 7 | "续航是首要考虑" |
| 智能驾驶 | 场景化任务 | 4 | 10 | 9 | 1 | "自动驾驶很省心" |
| 外观设计 | 五感-视觉 | 4 | 8 | 8 | 0 | "外观很有未来感" |
| 价格 | 判别标准 | 3 | 6 | 2 | 4 | "价格有点贵" |

**Sheet 4：五感体验评分表**

| 五感维度 | 具体体验点 | 用户描述 | 满意度(1-5) | 重要性(1-5) | 改进优先级 |
|---------|-----------|---------|------------|------------|-----------|
| 视觉 | 外观设计 | "流线型，像来自未来" | 5 | 5 | P1 |
| 视觉 | 内饰大屏 | "大屏很震撼" | 4 | 4 | P2 |
| 听觉 | 车内静音 | "比油车安静多了" | 5 | 4 | P2 |
| 听觉 | 音响效果 | "音响一般般" | 3 | 3 | P3 |
| 触觉 | 座椅舒适度 | "座椅有点硬" | 3 | 4 | P2 |
| 触觉 | 材质质感 | "塑料感有点强" | 3 | 3 | P3 |
| 嗅觉 | 车内气味 | "新车没什么味道" | 4 | 3 | P3 |
| 味觉 | - | - | - | - | - |

## 三、Key Aha Moment（关键洞察）

### 🔍 Aha Moment 1：用户把OTA升级当作"开盲盒"的惊喜体验

**冲突/反直觉点**：
- 传统认知：软件升级是麻烦事，需要专门花时间
- 用户实际：每次升级都充满期待，像收到礼物一样兴奋

**用户原话**：
> "每次OTA升级我都特别期待，就像开盲盒一样，不知道会有什么新功能。上次升级后多了个游戏，孩子在车上玩得很开心。有时候升级完发现多了个新功能，那种惊喜感就像白捡了个礼物。"

**背后洞察**：
- 软件定义汽车带来持续新鲜感，延长产品生命周期
- 用户愿意为"惊喜"和"期待感"付费，而非单纯功能
- OTA升级成为用户与品牌持续互动的触点

---

### 🔍 Aha Moment 2：充电等待时间被转化为"独处时光"

**冲突/反直觉点**：
- 传统认知：充电等待是痛点，浪费时间
- 用户实际：部分用户把充电时间当作难得的独处/放松时间

**用户原话**：
> "虽然充电要等半小时，但我反而觉得挺好。平时工作忙，这半小时我可以安静地在车里看看视频、回回消息，或者就是发呆。这是难得的独处时间，没人打扰我。"

**背后洞察**：
- 充电场景可转化为"第三空间"体验
- 用户需要的不只是快，还有充电过程中的体验
- 充电站可升级为休闲/办公/社交空间

---

### 🔍 Aha Moment 3：自动驾驶让驾驶从"负担"变成"享受"

**冲突/反直觉点**：
- 传统认知：驾驶是技能，需要专注和掌控感
- 用户实际：把驾驶交给系统后，反而更享受出行

**用户原话**：
> "以前开车特别是堵车的时候特别累，现在开了AP（自动驾驶）后，我可以看看风景、听听播客，甚至想想工作上的事。开车从负担变成了享受，我觉得这才是未来。"

**背后洞察**：
- 自动驾驶改变的不只是便利性，更是出行体验的本质
- 用户愿意为"省心"和"自由"支付溢价
- 未来汽车的核心价值可能是"移动空间"而非"驾驶工具"

---

## 四、对创新的启发（INSPIRATION）

### 💡 对应 Aha Moment 1 的启发

**创新机会**：
- 打造"惊喜订阅"模式，定期推送彩蛋功能
- 建立用户共创机制，让用户投票选择新功能
- 开发"功能盲盒"，随机解锁隐藏功能

**产品启示**：
- **功能层面**：增加更多彩蛋功能（游戏、主题、音效）
- **体验层面**：升级过程游戏化，增加期待感和仪式感
- **营销层面**：OTA升级作为营销事件，制造话题和社交传播

---

### 💡 对应 Aha Moment 2 的启发

**创新机会**：
- 充电站升级为"第三空间"，提供休闲/办公设施
- 开发"充电时光"服务（按摩椅、VR体验、咖啡吧）
- 推出"充电社交"功能，连接附近车主

**产品启示**：
- **功能层面**：车内增加娱乐/办公功能（大屏、投屏、会议模式）
- **体验层面**：充电过程可预约服务（按摩、洗车、购物）
- **营销层面**：充电站品牌化，打造车主社群空间

---

### 💡 对应 Aha Moment 3 的启发

**创新机会**：
- 开发"移动空间"模式，根据场景自动调整座舱
- 推出"出行即服务"，车内集成办公/娱乐/休息功能
- 建立"无驾驶"体验标准，重新定义出行品质

**产品启示**：
- **功能层面**：自动驾驶+座舱场景模式（办公/娱乐/休息）
- **体验层面**：无缝切换驾驶/乘坐模式，零焦虑出行
- **营销层面**：主打"解放时间"而非"自动驾驶技术"
