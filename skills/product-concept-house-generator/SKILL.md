# 产品概念屋内容生成 Skill

> 基于多角色协作流程，从产品机会描述到完整概念屋的系统化生成工具。适用于所有消费品品类。

## 触发条件

当用户需要：
- 基于产品机会描述生成完整产品概念屋
- 系统化分析产品机会（品类→用户→需求→价值→设计→卖点）
- 使用多角色协作方法生成产品概念
- 应用JTBD理论和贝恩B2C用户价值要素金字塔

**关键词**：产品概念屋、概念生成、JTBD、贝恩金字塔、用户画像、核心需求、产品卖点

## 使用方式

用户需要提供：
1. **产品机会描述**（必需）——描述市场机会、目标用户、痛点问题等
2. **产品机会需求**（可选）——具体的产品需求，用于指导设计要求生成

---

## 工作流程（8步多角色协作）

### Step 1: 品类识别

**角色**：市场分析师

**角色技能**：
- 具备强大的信息提炼能力，能从复杂的商业描述中迅速定位关键信息
- 对各行各业的产品分类有深入的理解

**任务目标**：
基于用户提供的产品机会描述，精准地识别并提炼出其中当前正在研究、优化的"目标品类"。

**工作流程**：
1. 仔细阅读用户提供的全部内容，思考描述的是针对哪个"目标品类"的机会
2. 将这个分类提炼成一个简洁、明确的"品类名称"，并将用于限定该品类边界、描述该品类的信息构建成"品类备注"

**输出格式（JSON）**：

```json
{
  "target_category": {
    "category_name": "品类名称",
    "category_notes": "品类边界描述、核心特征"
  }
}
```

### Step 2: 用户画像构建

**角色**：用户研究员

**角色技能**：
- 精通定性研究方法，能够通过文本描述洞察用户特征
- 擅长构建结构化、信息丰富的用户画像（Persona）

**任务目标**：
基于用户提供的"产品机会描述"和已明确的"目标品类"，为该品类的目标用户构建一个全面而精准的用户画像。

**工作流程**：
1. 分析用户提供的机会描述，并结合已识别的目标品类，识别出描述中针对的核心用户群体
2. 从机会描述中提取与该用户群体相关的所有信息
3. 将提取的信息结构化地整理成一个包含人口统计学特征、行为特征、痛点与挑战的用户画像

**输出格式（Markdown）**：

```markdown
### 目标人群画像
- **人口统计学特征**: [简要描述年龄、性别、职业、收入等]
- **行为特征**: [简要描述与品类相关的消费习惯、使用场景等]
- **痛点与挑战**: [简要描述用户在使用相关产品或服务时遇到的核心问题]
```

### Step 3: 核心需求提炼

**角色**：产品策略顾问

**角色技能**：
- 精通"Jobs-to-be-Done"（待办任务）理论，能够穿透用户行为表面，挖掘其背后最根本的动机和需求
- 具备卓越的归纳和提炼能力，能将分散的用户痛点聚合成清晰的核心需求
- 精通贝恩B2C用户价值要素金字塔，擅长分析用户的底层需求并将其用标准化的方式进行描述

**任务目标**：
基于已明确的"目标品类"和详细的"目标人群画像"，运用"Jobs-to-be-Done"和"贝恩B2C用户价值要素金字塔"理论，提炼出目标用户针对该品类的3-5个核心需求。

**工作流程**：
1. 深入理解目标品类的价值主张以及目标人群画像中描述的各项特征，特别是用户的"痛点与挑战"和"目标与期望"
2. 运用"Jobs-to-be-Done"理论进行思考：在特定场景下，这个用户群体想要"雇佣"该产品来完成什么核心任务（Job）？
3. 基于第二步识别出的核心任务（Job），通过"贝恩B2C用户价值要素金字塔"将其转化为驱动用户行为的本质需求
4. 对所有识别出的需求进行优先级排序和归纳，总结出3-5个最关键、最有价值的核心需求

**优先级原则**：排序应优先从品类相关性角度出发，而不应该单纯关注价值要素金字塔中更高层次的需求。

**贝恩B2C用户价值要素金字塔**：

```
┌─────────────────┐
│  激励（自我实现） │  ← 个性化、成就感
├─────────────────┤
│  赋能（生活改善） │  ← 省时、省钱、健康
├─────────────────┤
│  基础（功能满足） │  ← 质量、可用性
└─────────────────┘
```

**输出格式（JSON）**：

```json
{
  "core_demands": [
    {
      "序号": "核心需求1",
      "需求名称": "需求名称",
      "需求描述": "不超过50字的描述"
    },
    {
      "序号": "核心需求2",
      "需求名称": "需求名称",
      "需求描述": "不超过50字的描述"
    },
    {
      "序号": "核心需求3",
      "需求名称": "需求名称",
      "需求描述": "不超过50字的描述"
    }
  ]
}
```

### Step 4: 价值维度拆解

**角色**：产品策略专家

**角色技能**：
- 精通价值主张设计（Value Proposition Design）
- 擅长将抽象的用户需求，系统性地解构为具体、可感知的产品价值维度

**任务目标**：
基于品类核心需求列表，结合目标品类背景，将每一条核心需求从产品实现的角度，拆解为具体的产品价值维度。

**工作流程**：
1. 深入分析品类核心需求，并始终围绕目标品类的品类特性进行思考
2. 运用价值主张设计理论，从产品视角对核心需求逐条进行思考：为了满足这条"核心需求"，产品需要在哪些方面为用户创造价值？
3. 将这些价值创造点分别进行归纳、提炼为明确且相互独立的产品价值维度

**示例**：

核心需求：高效完成清洁
↓
价值维度：
- 清洁速度（时间效率）
- 操作便捷性（使用体验）
- 覆盖范围（功能完整性）
- 维护简单性（后续成本）

**输出格式（JSON）**：

```json
{
  "core_demand_1": {
    "需求名称": "xxx",
    "需求描述": "xxx",
    "价值维度": {
      "价值维度1": "维度描述",
      "价值维度2": "维度描述"
    }
  },
  "core_demand_2": {
    "需求名称": "xxx",
    "需求描述": "xxx",
    "价值维度": {
      "价值维度1": "维度描述",
      "价值维度2": "维度描述"
    }
  },
  "core_demand_3": {
    "需求名称": "xxx",
    "需求描述": "xxx",
    "价值维度": {
      "价值维度1": "维度描述",
      "价值维度2": "维度描述"
    }
  }
}
```

### Step 5: 设计要求生成

**角色**：高级产品设计师

**角色技能**：
- 精通用户体验设计（UX Design）与需求转化
- 能够将抽象的产品价值与具体的用户场景需求相结合，转化为可执行的产品设计方案

**任务目标**：
针对每个核心需求，将其下的价值维度和用户的产品机会需求进行交叉分析，为每一个价值维度提出具体的产品开发设计要求。

**工作流程**：
1. 仔细阅读用户的产品机会需求，并理解其背后的用户场景和期望
2. 回顾并分析当前核心需求的每一个价值维度
3. 针对列表中的每一个价值维度，思考并回答："我们在当前价值维度应该采取哪些产品功能或体验设计，才能满足用户的产品机会需求？"
4. 将思考结果整合成一系列具体、清晰、可执行的产品开发设计要求

**输出格式（JSON）**：

```json
{
  "核心需求1": {
    "需求名称": "xxx",
    "需求描述": "xxx",
    "产品价值维度": {
      "价值维度A": {
        "产品开发设计要求": ["设计要求1", "设计要求2"]
      },
      "价值维度B": {
        "产品开发设计要求": ["设计要求1", "设计要求2"]
      }
    }
  }
}
```

### Step 6: 卖点提炼

**角色**：营销文案专家（Copywriter）

**角色技能**：
- 极强的用户洞察能力，能够精准捕捉目标人群的心理和痛点
- 卓越的文字提炼能力，能将复杂的产品功能和设计理念，转化为一句直击人心的响亮卖点（Slogan）

**任务目标**：
基于当前核心需求的产品开发设计要求和目标人群画像，为该核心需求提炼并创造一个响亮、有吸引力的产品核心卖点。

**工作流程**：
1. 汇总所有价值维度和产品开发设计需求，洞察这些设计要求背后能为用户带来的最核心、最独特的利益点是什么
2. 回顾目标人群画像的全部信息，特别是用户的痛点、期望和常用语言风格
3. 将第一步提炼的核心利益点，用最符合目标人群特点的语言风格进行包装，创造出一句简短、易记且极具吸引力的产品卖点

**输出要求**：提炼出的卖点不超过15个字。

**输出格式（JSON）**：

```json
{
  "核心需求1": {
    "需求名称": "xxx",
    "需求描述": "xxx",
    "需求卖点1": "不超过15字的Slogan",
    "产品价值维度": {
      "价值维度A": {
        "产品开发设计要求": ["设计要求1", "设计要求2"]
      }
    }
  }
}
```

### Step 7: 循环处理核心需求2-5

对核心需求2至核心需求5分别执行Step 5和Step 6。

**存在性判断逻辑**：
- 如果核心需求4不存在（即Step 3只生成了3个核心需求），则跳过核心需求4的处理，直接输出"核心需求4不存在"
- 如果核心需求5不存在（即Step 3只生成了3-4个核心需求），则跳过核心需求5的处理，直接输出"核心需求5不存在"
- 只处理实际存在的核心需求

### Step 8: 概念屋汇总输出

**角色**：文案专员

**任务目标**：
针对产品机会目标，汇总所有产品开发要求，转化为Markdown格式输出。

**工作流程**：
1. 汇总所有核心需求的JSON格式信息
2. 忽略不存在核心需求的信息
3. 从产品机会描述提炼标题

**输出格式（Markdown）**：

```markdown

> 基于产品机会：[用户输入的机会描述摘要]
```

```markdown
# 智能扫地机器人产品概念
> 基于产品机会：针对都市年轻家庭，开发一款智能扫地机器人...

## 一、目标品类

**品类名称**：智能扫地机器人
**品类备注**：面向家庭场景的自主清洁设备，具备智能导航、自动集尘、低噪音运行等特征，区别于传统随机碰撞式扫地机

## 二、目标人群画像

- **人口统计学特征**：25-35岁都市双职工，中高收入，有宠物或小孩
- **行为特征**：工作繁忙，注重生活品质，愿意为便利付费，对噪音敏感
- **痛点与挑战**：没时间打扫、宠物毛发难清理、现有产品噪音大影响孩子/宠物休息

---

## 三、核心需求与卖点

### 核心需求1：深度清洁
**需求描述**：彻底清除地面灰尘、毛发，无需二次人工打扫
**产品卖点**：吸得净，才省心
**价值维度与设计要求**：

| 价值维度 | 产品开发设计要求 |
|----------|------------------|
| 清洁力 | 8000Pa飓风吸力，V型滚刷防缠绕设计，专门针对宠物毛发优化 |
| 覆盖率 | LDS激光导航，AI路径规划，确保边角无遗漏 |
```
