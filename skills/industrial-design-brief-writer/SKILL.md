# 工业设计Brief撰写 Skill

> 通用工业设计Brief撰写助手，提供结构化框架、撰写指导和快速模板。适用于所有消费品品类，文中示例保留行业原样仅供示范。

## 一、触发条件

当用户需要：
- 撰写工业设计Brief/设计任务书
- 明确设计需求文档结构
- 获取Brief撰写模板
- 检查Brief完整性

**关键词**：工业设计Brief、设计任务书、设计需求文档、ID brief、写brief

## 二、核心能力

### 2.1 Brief结构框架生成

根据项目类型（课题/项目）生成对应的Brief结构：

**课题任务书结构（探索阶段）**：

1. 产品策划信息（背景、定位、卖点）
2. 用户信息（画像、场景、需求排序）
3. 竞品信息（对标、超越点）
4. 设计要求（风格、ID/UI/CMF）
5. 技术红线（性能、成本）
6. 项目团队
7. 时间计划

**项目任务书结构（执行阶段）**：

1. 产品基本信息（型号、类别、定位）
2. 核心卖点（优先级排序）
3. 目标用户画像
4. 设计要求（整体要求、ID、UI、CMF）
5. 技术约束
6. 交付标准
7. 时间计划

### 2.2 各模块撰写指导

#### 模块1：产品定位

**撰写公式**：

```
为 [目标人群] 设计 [产品类型]，
通过 [核心差异点] 解决 [核心痛点]，
实现 [商业目标]
```

**示例**：为25-35岁新中产家庭设计万元价位集成灶，通过超薄悬浮机头设计解决传统产品厚重感问题，打造该价位段颜值标杆。

#### 模块2：核心卖点

**要求**：
- 主卖点1-3个，明确优先级
- 每个卖点说明对设计的指导意义
- 明确哪些卖点必须在设计中突出

**示例**：
1. 【主卖点】超薄悬浮设计 —— 必须成为视觉焦点
2. 【次卖点】AI智能交互 —— 通过UI/交互显性化
3. 【支撑卖点】5.0kW猛火 —— 通过CMF突出火力感

#### 模块3：目标用户画像

**必填维度**：
- 核心人群（年龄、身份、消费能力）
- 使用场景（环境、频率、痛点）
- 审美偏好（风格倾向、参照物）
- 决策因素（价格敏感、品牌偏好）

**示例**：
- 人群：25-35岁都市新中产，女性主导决策
- 场景：开放式厨房，与客厅相连
- 偏好：极简、科技感、高级感
- 决策：颜值>功能>品牌>价格

#### 模块4：设计要求

**整体要求撰写框架**：

```
【外观竞争力要求】
- 具体要求：通过XX设计让XX部件成为视觉焦点
- 衡量标准：核心部件颜色/形态与其他显著不同
- 商业支撑：线下陈列和线上详情页重点突出
```

**风格描述原则**：
- 具体而非抽象（❌"要有设计感" → ✅"机头厚度≤80mm"）
- 可衡量（❌"要好看" → ✅"第一眼停留时间>5秒"）
- 有优先级（"极简:科技感 = 3:4"）

**风格具象化方法**：
- 对标参照物（如：特斯拉Cybertruck的硬朗线条）
- 聚焦核心部件（如：机头采用悬浮式设计）
- 聚焦场景（如：像一件"科技艺术品"）

#### 模块5：技术红线

**必含内容**：
- 性能参数（最低要求、目标值）
- 成本约束（总成本、外观件占比）
- 其他约束（结构空间、安规认证）

**示例**：

| 参数 | 最低要求 | 目标值 |
|------|----------|--------|
| 风量 | ≥17m³/min | 19m³/min |
| 噪音 | ≤72dB | 68dB |

**成本约束**：外观件成本不超过总成本的15%

### 2.4 Brief质量检查

**检验清单**：
- 设计师看完后能画出草图
- 工程师看完后能评估可行性
- 市场人员看完后能写卖点文案
- 每个要求都有衡量标准
- 风格描述具体可感知
- 技术约束明确
- 时间计划合理

**常见错误检查**：
- 无信息过载（核心内容<8页）
- 无矛盾要求（有明确优先级）
- 有用户视角（非纯技术参数）
- 有创新空间（非过度约束）

### 示例3：Brief质量检查

**用户输入**：
> 帮我检查一下这个Brief [粘贴Brief内容]

**Skill输出**：

```markdown
## Brief质量检查报告

### ✅ 优点
1. 产品定位清晰
2. 用户画像完整
3. 时间计划详细

### ⚠️ 改进建议
1. 【设计要求】"要有设计感"过于抽象，建议改为具体指标
2. 【技术约束】缺少成本上限
3. 【卖点】建议明确每个卖点对设计的指导意义

### ❌ 关键缺失
- 缺少衡量标准，建议为每个设计要求配套验收标准

### 修改示例

原文：机头要有设计感
建议：机头采用悬浮式设计，视觉厚度≤80mm，
衡量标准：用户第一眼停留时间>5秒
```

## 五、边界与限制

1. 不提供具体设计方案 —— 只提供Brief撰写框架
2. 不替代专业判断 —— 技术参数需由工程师确认
3. 需结合行业特性 —— 不同行业Brief侧重点不同
